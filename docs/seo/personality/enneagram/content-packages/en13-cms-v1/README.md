# English Enneagram 13-Page CMS Package v1

This is the CMS-authoritative English counterpart to the Chinese EN13 package.
It covers the hub, nine core types, and three centres under
`/en/personality/enneagram`. The package is draft-only: it authorizes no CMS
write, publish, indexability, sitemap, LLM, search, or deployment action.

English copy is independently localized from the Chinese package's route and
section structure. It uses Enneagram only as a self-observation and
communication-reflection framework; it is not diagnosis, selection, prediction,
or a fixed identity label.

## Evidence contract v1

All 13 pages contain a visible `evidence_and_limitations` section and two
traceable evidence notes. `hook-2021` supports only the cautious research
boundary; it does not validate a page or an individual's type. The internal
claim-boundary source records prohibited uses and is explicitly not scientific
validation. English and Chinese use the same stable source IDs while keeping
their claims and limitations independently localized.
