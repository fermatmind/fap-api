# 费马职业测试：独立题本与评分试测版

2026-11-14。范围：作答内容、个人侧评分、对单个有证据岗位的比较。此版本未注册到线上测评入口，也不覆盖既有的 60/140 题或读写历史尝试。

## 竞品证据与取舍

- [Truity 测验页](https://www.truity.com/test/career-personality-profiler-test)给出 94 题、约 10–15 分钟，并说明采用 Holland Code 和 Big Five。官方产品页支持这两类构念，不公开可复刻的完整计分和岗位权重。94 题是作答体量参照，不是信效度依据。
- [CareerExplorer 测验说明](https://www.careerexplorer.com/career-test/)与[技术手册](https://www.careerexplorer.com/science/)描述兴趣、工作环境偏好、人格、背景与目标，以及通过职业侧数据做比较。150+ 是特征量口径，不能当题数；未获得可复刻的当前题本、职业特征权重或训练数据。
- 费马旧增强版共 96 道活动、18 道环境、18 道角色偏好、8 道质量题。活动/环境/角色合成权重为 70/15/15，最终仍是六维兴趣。旧模型保留原语义。
- 新版对标「比较职业时需要哪些不同信号」。不抽取一套未经试测的短版大五、不估算抗压/胜任力，不照搬竞品题目。工作方式只问实际会遇到、两种方式都合理的取舍。

## 题本

中英双语题目和答案是同一份资源文件：`backend/resources/assessment/career-v1/questions.json`。当前 94 题是试测题本，可用试测结果和题目用途删减。题本条目编号稳定，量表锚点分别设定。

| 模块 | 题量 | 回答的实际问题 |
| --- | ---: | --- |
| 活动兴趣 | 42（六维各七题） | 我愿意做哪些具体工作？ |
| 工作方式 | 20（五轴各四题） | 同一任务有两种做法时，我更愿意怎么做？五轴分别是协作频率、方法自主度、任务切换、对外接触、工作中的活动量。 |
| 看重的工作条件 | 24（六项各四题） | 我重视的是工时可预期、学习支持、收入稳定、看得见成果对他人的作用、晋升路径，还是地点灵活？各项独立，可以同时重视。 |
| 当前起点和约束 | 8 | 职业阶段、经验时长、教育程度、探索目标、再培训时间、想延续的经历，以及能否接受固定夜班和频繁过夜出差。原样记录，不计入个人量表。 |

独立保存题本版本与评分版本。题干改变含义、换题或改变作答锚点须新建题本版本；评分规则变化须新建模型版本。当前源码不自动重用 60 题成绩，也不重算旧 140 题历史。

## 评分契约

- 个人侧：每题 1–5，反向端点题先用 `6-x` 统一方向，轴分为 `25 × (有效答案均值 − 1)`。七题轴至少六题；四题轴至少三题。未知与跳过用 null，和明确选择中间选项不同，保留覆盖数。不输出百分位、类型诊断或能力估计。
- 兴趣：以岗位同口径的六维任务权重求用户轴分的加权均值，减去用户六轴均值，除以二后加 50。它描述偏向：同时高/低不会虚增方向分；完全平坦、缺任何一维、岗位权重全为零均不比较。并列保留，接近不会被名次放大；极差供后续试测校准，不预设临界分。
- 工作方式：在一致的双端口径上，用 `100 − |个人偏好 − 岗位典型方式|` 对照，五轴齐才汇总等权平均。高低端无好坏。
- 工作条件：用个人重要度为权重对岗位实际提供程度做加权平均。重要度 0 的项不计权；有权重而资料缺失则该组总分空缺。条件多提供一点，不会因为比用户的重要度分高就被惩罚。
- 明确约束：只有用户明确不能接受且岗位证据确认必须才标冲突；资料未知则为未知。其余起点信息留给后续入行路径核对，不从学历或资历判定某人不适合。无合格方向时也不自动取消约束。
- 同一职业可能因雇主、地区、团队而异。输入须注明职业身份或具体岗位、市场、日期、来源、映射口径。职业正文、O*NET SOC 号与现有职业库规模不等于同口径的个性化岗位画像。未知不以 0 或 50 填充；不按每个岗位剩余字段重分权重，也没有单一匹配率。

## 校准与对照

先按职业阶段找用户做中英认知访谈，核题意、陌生任务比例、耗时、跳过和重复感；优先比较完整试测题本与减题版，而非预设 94 必须留。用同一批有资料的岗位和同一套活动轴，随机打乱两组候选顺序进行盲测：兴趣基线与加入工作方式、条件及明确约束的版本，比较受试者能否选出一项愿意核对或尝试的方向，能否解释差异，及误挡方向与无证据率。试测单独检查重测稳定和中英可比性。现有合成测试只验证规则，没有验证量表效度、个性化增益或全库覆盖。
