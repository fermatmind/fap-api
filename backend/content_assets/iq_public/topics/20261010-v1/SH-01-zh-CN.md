# IQ与EQ：区别、测试选择和结果阅读

IQ与EQ关注不同的问题。认知测验通过具体任务观察推理等认知表现；情绪智力相关工具关注情绪信息的识别、理解、调节及相关行为，但可以采用能力任务、自我报告或情境判断，结果不能混用。

费马当前两种入口提供不同来源的信息：原创30题视觉推理练习记录一次题目作答表现；60题EQ自评整理你对情绪与关系倾向的自我描述。两种数字不能比较谁更高、谁更好，也不能拼成稳定人格类型或职业能力等级。

## 先比较方法，再选择工具

| 要比较的问题 | 费马视觉推理练习 | 费马EQ-60自评 |
|---|---|---|
| 你在做什么 | 比较图形关系，选择答案 | 描述自己通常怎样感受与行动 |
| 本次信息来自哪里 | 这组题目的作答表现 | 本次对自己的报告 |
| 内容范围 | 原创30题视觉矩阵任务 | 自我觉察、情绪调节、共情理解、关系管理四维 |
| 分数先怎么读 | 正确题数与正确率；Beta另按模拟来源理解 | 先确认字段与参照，再结合四维、作答质量与现实场景 |
| 不能直接推出什么 | 全部智力、稳定能力类型或职业上限 | 实际沟通能力、他人感受、工作表现或关系结局 |
| 更有用的下一步 | 在新材料中检验规则检查习惯 | 用具体事件和对方确认检验自我认识 |

EQ-60的四维是当前解释框架：自我觉察涉及自己的情绪与触发点；情绪调节涉及暂停、恢复和选择回应；共情理解涉及他人的可能感受与观点；关系管理涉及表达、协作、边界与修复。它不是MSCEIT或已经验证的能力测验。当前内容证据为初步，常模为阶段性，内部一致性、重测、结构、外部关联和跨语言／群体等值性仍需验证。

自评有反思价值，但“我认为自己能理解别人”与“这次确实理解了对方”不是同一种证据。共情需要确认猜测；关系管理也可以包括拒绝和清楚的边界，不等于迎合。

## 分数看起来相似，参照可能完全不同

视觉练习中的18/30 = 60%只表示答对比例。其公开Beta计算采用随机模拟基线，不能当成人群IQ或百分位，也不保证当前报告界面展示Beta。

EQ中若出现POMP，它表示在量表理论可得分范围中的位置，不是“超过多少人”。例如在一个纯教学假设中，某量表范围为20–100，得分80，则范围位置为(80−20)÷(100−20)×100% = 75%；这不是第75百分位，也不是本站当前公式说明。

标准分与百分位必须另看实际参照、版本和状态。EQ标准分不是IQ；阶段性参照也不能未经核查就解释为代表性人群排名。不要把两种分数相加、相减或用于选人。

## 同一项目延期，可能有两个不同问题

下面是合成情境，不是用户数据、测验题或效果证据。

林在项目复盘中发现，团队把“先确认需求、再制作、最后验收”三个串行任务按并行任务估算，导致工期过短。与此同时，林说“你的估算错了”后，同事停止补充信息。林一直认为自己善于理解别人，但还没有确认这次沉默意味着什么。

第一步是把观察写清：进度表中的依赖关系有错误；对话中对方停止解释。前一项要检查任务假设、依赖和工期，后一项要检查自己的反应、表达和对对方的猜测。不能由计算错误给同事贴“低IQ”标签，也不能从沉默认定“低EQ”。

第二步是寻找替代解释。估算错误可能来自需求缺失、专业知识不足或时间压力；沉默可能是疲劳、需要思考、权力差异，或担心被责备。不同原因需要不同调整，测分无法代替现场证据。

第三步是共同处理。先标出哪些任务必须先后完成、哪些条件仍未知，再问：“你最担心的是工期、资源，还是责任安排？也可能是其他问题。”让同事纠正猜测，确认后再商定一项具体调整，例如重新分配验收时间或明确需求负责人。理解困难不要求林承诺无法承担的额外任务。

第四步是复核：新排期能否经依赖与反例检查，对方是否确认问题被准确理解，责任是否更清楚。若没有改善，应再查资源、授权、任务定义或沟通时机；不要只重复做测试。存在羞辱、报复或安全风险时，不要求当事人靠更高“情商”继续维持对话，应转向适当支持与渠道。

## 按你现在的问题选择阅读路径

### 1. 我想体验一种工具

想体验图形规则判断，先看[原创30题视觉推理练习](/zh/tests/iq-test-intelligence-quotient-assessment)。想整理情绪与关系的自我感知，先看[60题情绪与关系自评](/zh/tests/eq-test-emotional-intelligence-assessment)。选择依据是要观察什么，不是谁能给出更高的数字。

### 2. 我想读懂一个分数

IQ相关成绩从[智商测试分数与限制说明](/zh/articles/iq-test-score-and-limits-explained)开始，分清正确率、Beta和人群参照。EQ先读[60题情绪与关系自评入口](/zh/tests/eq-test-emotional-intelligence-assessment)，确认四维、自评身份和计分说明。遇到百分位或标准分时，再核实际报告中的参照说明，不能拿POMP代替。

### 3. 我想理解概念和测量范围

读[费马智商测试使用指南](/zh/articles/iq-test-tool-guide)，理解本站视觉任务与综合认知评估的区别；读[60题情绪与关系自评入口](/zh/tests/eq-test-emotional-intelligence-assessment)，核对自评方法与使用边界，再结合本页比较理解它与能力任务的区别。这些是现有工具层面的阅读入口；本页已给出两类信息不能互换的核心答案。

### 4. 我想练习一个可观察动作

推理方面可读[智商测试练习与复盘](/zh/articles/iq-test-growth-guide)，从检查规则与反例开始。情绪与关系方面可用本页项目延期案例，把反思落到一个具体事件：说出感受、确认对方担忧、提出明确请求或边界。用新材料和现实反馈复核，不以测分上涨代替实际变化。

### 5. 我想把问题用于工作复盘

先用本页项目延期案例复盘真实任务，分别记录依赖关系、资源条件、表达和同事反馈，再选择一个可观察的调整。本站两种结果不用于招聘、晋升、绩效或岗位筛选，也不证明职业成功。工作中首先要问任务要求和资源条件，再寻找对应证据。

## 为什么这里没有“谁更重要”的统一比例

推理和情绪相关活动在真实情境中可能同时参与，不能简单切成“智商做事、情商做人”。一个问题需要什么证据，取决于任务与情境。没有通用的“成功20%靠IQ、80%靠EQ”比例，也不能从本站两种分数推导个人成功概率。

关于情绪智力研究中的能力测量与自我报告区别，可参见[Mayer、Salovey与Caruso的理论综述](https://aec6905spring2013.wordpress.com/wp-content/uploads/2013/01/mayersaloveycaruso-2004.pdf)。它提供方法区分，不把其他工具的效度转给EQ-60。关于分数解释与用途的匹配，参见[教育与心理测验标准](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf)。
