`BIG5-AUTHORITY-V2-RANGE-EXTRAVERSION-12` prepares exactly eight backend-authoritative draft candidates: EN/zh-CN extraversion-high, extraversion-mid, and extraversion-low V2 range pages, plus the EN high-extraversion and low-extraversion legacy canonicals.
