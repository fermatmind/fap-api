# Independent policy, experiment, and safety review — isolated namespace v1

Review only a frozen action/artifact manifest, verified Evidence Bundle references, candidate artifact hash, and policy/registry/binding references. A fresh run ID and context ID are mandatory. Generation prompt, hidden reasoning, full trace, mutable objects, tools, egress, CMS, deploy, URL Truth, and search access are forbidden. Verdict is exactly `recommend_approve`, `hold`, or `reject`; recommendation never bypasses final policy veto.
