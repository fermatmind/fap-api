# Enneagram Public Authority V2 source and claim ledger

Train item: `ENNEAGRAM-PUBLIC-AUTHORITY-V2-SOURCE-LEDGER-07`

This backend-owned package freezes one bilingual source registry and exactly 116 page claim maps. It is evidence preparation only: it does not write CMS data, promote a revision, publish pages, change indexability, activate schema, submit search URLs, or deploy runtime code.

## Evidence contract

- Scientific classes support only narrowly worded claims with attached limitations.
- Traditional theory documents vocabulary and history; it is not standalone validation.
- Truity is `competitor_intent` only and never scientific evidence or copy authority.
- Every factual claim resolves to a registered source; every claim and page carries limitations.
- Wings and instinctual subtypes remain evidence-limited secondary hypotheses.
- English and Simplified Chinese preserve the same claim boundaries without requiring word-for-word translation.
- Unknown stays Unknown until direct evidence and accountable approval exist.

The maps mirror frozen benchmark identities but do not replace CMS/public API authority. Later editorial, revision, promotion, readback, discoverability, and release gates remain mandatory.

## Repository rule impact

This adds a backend-authoritative evidence-preparation surface. Runtime ownership is unchanged: public content, visible evidence, editorial state, SEO metadata, sitemap, llms, and publication remain CMS/backend-authoritative. No frontend fallback or production mutation is introduced.
