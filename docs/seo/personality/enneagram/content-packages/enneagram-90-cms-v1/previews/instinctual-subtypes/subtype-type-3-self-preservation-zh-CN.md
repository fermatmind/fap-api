# 第 3 型·自保本能副型

> Non-authoritative mechanical preview of `type-3/self-preservation` (zh-CN).

第 3 型·自保本能副型把第 3 型的成就与可见价值动机和自保注意结合，常见假设是通过可靠工作、资源安排与可交付成果建立安全感。它是观察工具，不是诊断或固定身份。

## 第 3 型·自保本能副型是什么？

第 3 型·自保本能副型 描述的是第 3 型核心动机与自保注意优先级的组合：核心仍是「成果、价值确认与可见表现」，本页只讨论它可能如何先扫描身体余量、时间边界、资源账单和可交付底线。它不是医学诊断，也不是把人固定成一个副型；更安全的用法，是把它当作观察 把表现误当成真实偏好 是否反复出现的工作假设。

判断 type-3/self-preservation 时不要只看外在行为。资源紧张、健康波动或岗位责任也会制造相似表现；第 3 型还要额外记录成功标准、真实偏好和没有评价时的行动，确认问题是否真围绕「成果、价值确认与可见表现」。若自保线索不能解释下一次注意点、冲突优先级和恢复方式，就应降低这个标签的可信度。

## 核心类型与注意优先级如何组合

第 3 型模型先问：什么让人觉得必须调整选择、证明价值或守住边界。本页再问自保注意是否把这种核心动机推向身体余量、时间边界、资源账单和可交付底线。因此，type-3/self-preservation 的重点不是“多了一个本能”，而是核心动机通过哪类信息最早启动。

一个可执行的检查顺序是：先写成功标准，再写真实偏好，第三步写没有评价时的行动，最后标出把安全感压缩成不停优化资源是否正在发生。如果这些线索只随工作制度、关系阶段或短期压力出现，环境解释优先于副型解释。

## 资源、群体、连接、风险与恢复中的信号

自保识别不靠单个标签，而靠连续情境。观察一个普通决定时，先看是否最早扫描身体余量、时间边界、资源账单和可交付底线；观察冲突时，看这个优先级是否改变了表达、退让、推进或恢复顺序；观察复盘时，看它是否仍围绕「成果、价值确认与可见表现」而不是只服务表面形象。

反例必须写清楚：资源紧张、健康波动或岗位责任也会制造相似表现。如果同一行为能被职责、资源约束、文化礼貌、近期压力或关系历史充分解释，就不要把它直接归入 type-3/self-preservation。

## 工作、关系、学习与高压表现

工作中，第 3 型·自保本能副型可能把抽象目标转换为通过可靠工作、资源安排与可交付成果建立安全感的具体路径，并主动管理可见度与可信度。关系中，可能以完成、提升或共同结果表达关心，却较少呈现尚未整理的需要。学习中，偏好可衡量进展和能转换为实际成果的反馈。

高压下的风险是把休息延后到所有指标完成之后，让忙碌本身成为价值证明，并低估身体和关系账单。这会缩窄注意，却不代表人格必然如此，也不构成职业表现或关系结局预测。持续痛苦、睡眠问题或功能受损需要相应支持，不能由副型叙事替代。

## 条件合适时可能形成的资源

当自保注意与第 3 型核心配合良好，资源不是抽象优点，而是更早看见身体余量、时间边界、资源账单和可交付底线，并把「成果、价值确认与可见表现」转成可执行、可复盘的选择。它可能帮助人安排优先级、说明边界、减少误读，并在压力中保留一个可验证的下一步。

这些资源要按 type-3/self-preservation 的场景结果验证：成功标准是否更清楚，真实偏好是否被相关人理解，没有评价时的行动是否进入复盘，反例是否能改变结论。若资源最后变成把安全感压缩成不停优化资源，就需要回到边界、同意和真实影响，而不是继续强化副型形象。

## 注意过窄时会漏掉什么

第 3 型·自保本能副型 的主要风险，是把身体余量、时间边界、资源账单和可交付底线看得过窄，以至于忽略身体、群体和关键连接之间的相互修正。第 3 型核心已经容易围绕「成果、价值确认与可见表现」形成紧张，自保优先级若失衡，就会把把表现误当成真实偏好隐藏在看似合理的理由里。

type-3/self-preservation 的警讯要写得具体：是否为了维护成功标准而省略反例，为了真实偏好降低同意质量，或为了没有评价时的行动推迟恢复。若改变资源、角色、公开评价或关系距离后模式明显减弱，说明情境因素更强。
