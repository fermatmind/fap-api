# RIASEC 结果正文维护

## 唯一中文编辑入口

`backend/content_assets/riasec` 是中文私有结果正文的唯一编辑目录。文件清单由 `RiasecPrivateResultCompileService::SOURCE_CONTRACT` 绑定；`compiled/` 是确定性生成产物，禁止手改或作为第二套文案维护。修订沿用现有文件和稳定标识，不创建另一套 result_page 或版本目录。

页面按“摘要 → 六维解读 → 组合探索 → 职业活动探索”衔接。摘要只提示兴趣重点；六维解读解释活动性质、得分含义和现实条件；组合内容解释两个兴趣如何共同出现；活动卡提供可执行的例子。兴趣解释不能冒充能力评价或具体职业匹配。前端的自主工作方式选择不属于测评推断。

- 删除上述行内不参与投影的商业扩展说明。未删除既有测评题目、计分包、兼容字段、历史快照和不可变运行时 release。
- 140Q 分层、质量、接近分、反馈、分享、PDF、历史与比较资产仍有后端调用方。当前交互页面不展示某模块，不代表其余消费者已经退役，不能仅按页面截图删文件。

## 编辑依据与限度

六类职业兴趣的概念与用途参考 O*NET Interest Profiler 官方说明与技术手册：

- https://www.onetcenter.org/IP.html
- https://www.onetcenter.org/reports/IP_Manual.html

这些资料支持六类兴趣的概念及职业探索用途，不构成本产品 60Q/140Q 的效度证据，也不验证本次自编活动练习。活动是编辑性探索示例，不是标准化干预、技能测试或职业推荐。一次练习的体验不用于重算兴趣得分。

## 生成与验收

在 backend 运行 `php artisan riasec:private-result-compile`。同次提交纳入源文件与生成的 manifest/artifact。验证六维与三档解读、120 个有序三字码的活动覆盖、缺失内容关闭、语言边界、编译确定性与运行时权威一致性。
