# Small PR Queue

Shared defaults for every card unless overridden:

- Repo: `fap-api`
- Forbidden actions: CMS write/publish/import, article creation/update, Search Channel enqueue, search-provider submission, URL Truth write, sitemap/`llms`/schema/hreflang mutation, fap-web edit, deploy, runtime/API mutation, database write, title/meta/FAQ/body copy write, competitor page generation, GSC metric invention, screenshot metrics, raw GSC payload exposure, private URL public targeting.
- Local checks: `python3 -m json.tool <output>/scan_manifest.json >/dev/null`, `git diff --check`, `git diff --cached --check`.
- Expected GitHub checks: repository required checks must pass; staging/deploy workflows are not waited on unless explicitly required.
- Allowed files: only the declared generated output path unless a future explicit authorization says otherwise.
- Stop conditions: dirty scope cannot be isolated, runtime unavailable for required readback, required local check fails, GitHub required check fails, task needs held mutation, authority ambiguity, or dependency not complete.

## Per-Card Scope Template

Every card's exact scope is to create the listed output path with an `EXECUTIVE_DECISION.md`, a card-specific matrix/readback/report file, `NEXT_EXACT_AUTHORIZATION_PROMPTS.md` when useful, and `scan_manifest.json`. No other files are allowed unless a future operator prompt explicitly changes the scope.

Evidence inputs are the current acceptance scan, runtime gap scan, lane-specific prior scans, and the docs named in the goal. Cards that require live runtime readback may fetch public pages only. Cards that mention GSC may inspect existing generated/read-model evidence only; no live GSC call is authorized.
